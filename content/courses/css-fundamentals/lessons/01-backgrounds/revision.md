# مراجعة سريعة

- `background-image: url("...")` لوضع صورة.
- `repeat` (الافتراضي) · `repeat-x` · `repeat-y` · `no-repeat`.
- `background-position`: `top` / `bottom` / `left` / `right` / `center` والترتيب مش مهم.
- `background-attachment`: `scroll` بتتحرك مع العنصر، `fixed` ثابتة على الشاشة.
- `background-size`: `cover` بتملا وممكن تقص، `contain` كاملة وممكن فراغ.
- `linear-gradient(to bottom, red, blue)`: أحمر فوق وأزرق تحت.

✅ جرب الكويز لما تخلص.
